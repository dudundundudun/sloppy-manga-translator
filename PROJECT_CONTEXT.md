# Контекст проекта: Local Manga / Manhwa / Manhua Translator (v1.0.0)

Этот документ содержит полное техническое описание, историю разработки, особенности окружения и структуру всех файлов локального переводчика манги/манхвы/маньхуа. Скопируйте или прикрепите этот файл (вместе с архивом `manga_translator_v1.0.0.zip`) в начале нового чата, чтобы продолжить разработку без потери контекста.

## 1. Аппаратное и программное окружение пользователя
* **ОС:** Windows 11
* **Рабочая папка проекта:** `C:\Users\Alexey\Documents\manga-translator`
* **Папка расширения Chrome:** `C:\Users\Alexey\Documents\manga-translator\extension`
* **Видеокарта:** NVIDIA GeForce RTX 5070 Ti (16 ГБ VRAM, архитектура Blackwell)
* **Python:** Python 3.14 (`C:\Users\Alexey\AppData\Roaming\Python\Python314`)
* **Ключевые установленные версии пакетов:**
  * `torch 2.10.0+cu130` (CUDA 13.0)
  * `numpy 2.4.4`
  * `opencv-python 5.0.0.93`
  * `ultralytics` (YOLOv8), `manga-ocr`, `fastapi`, `uvicorn`, `httpx`, `pillow`
* **ВАЖНОЕ ОГРАНИЧЕНИЕ ПО УСТАНОВКЕ ПАКЕТОВ (`pip`):**
  На Python 3.14 нельзя запускать обычную установку пакетов со старыми закрепленными зависимостями (таких как `simple-lama-inpainting` или `easyocr`) без флага `--no-deps`, иначе `pip` попытается понизить версию `numpy` и собрать старый `numpy` из исходников (или перезаписать `opencv-python` на `opencv-python-headless` с ошибкой `WinError 5: Отказано в доступе` на `cv2.pyd`).
  * Поэтому дополнительные пакеты ставятся строго через `--no-deps` (см. `install_multilang_ocr.bat`).
* **ВАЖНОЕ ОГРАНИЧЕНИЕ ПО `.bat` ФАЙЛАМ В WINDOWS:**
  Все `.bat`-файлы (`start_gui.bat`, `start_server.bat`, `register_chrome_launcher.bat`, `install_multilang_ocr.bat`, `translate_folder.bat`, `test_page.bat`) должны содержать **только ASCII (английские символы)** и окончания строк `CRLF (\r\n)`.
* **Локальные LLM-серверы пользователя:**
  1. **Ollama** (`http://127.0.0.1:11434`) — основные рабочие модели: **`qwen3.5`** / **`qwen2.5:7b`**.
  2. **Unsloth Studio** (`http://127.0.0.1:8888`, OpenAI-совместимый API `/v1/models` и `/v1/chat/completions`) — опциональный локальный сервер (например, для **`Qwen 3.8 27B`**).
* **Особенность сети (VPN / Системный прокси):**
  Во всех клиентах `httpx` используется `trust_env=False` и переменные окружения `NO_PROXY="127.0.0.1,localhost"`.

## 2. Схема расположения файлов по папкам (v0.9.9)

```text
C:\Users\Alexey\Documents\manga-translator\
├── PROJECT_CONTEXT.md             # Полное описание проекта и контекст (v0.9.9)
├── gui_app.py                     # Десктопное графическое приложение (Tkinter + Pillow, автономно от Chrome)
├── start_gui.bat                  # Быстрый запуск локального десктопного GUI (чистый ASCII + CRLF)
├── web_studio.html                # Локальная Веб-Студия (доступна на http://127.0.0.1:5000/)
├── ocr_engine.py                  # Детекция бабблов (YOLOv8) + свободного текста вне бабблов (CRAFT + OpenCV) + OCR
├── translator.py                  # Перевод на EN, RU и транслитерация в Ромадзи (Hepburn Romaji) через Ollama/Unsloth
├── cleaner.py                     # Удаление текста из бабблов и свободных надписей на фоне (SimpleLama / TELEA)
├── renderer.py                    # Овальная и прямоугольная верстка с выбором мин./макс. шрифта (min/max font size)
├── server.py                      # FastAPI сервер (порт 5000, продолжение папки, остановка, переперевод отдельных страниц)
├── cli_client.py                  # Консольный клиент для test_page.bat и translate_folder.bat
├── start_server.bat               # Ручной запуск локального сервера (чистый ASCII + CRLF)
├── install_multilang_ocr.bat      # Безопасная установка EasyOCR (--no-deps) для KO/ZH и CRAFT-детектора (ASCII + CRLF)
├── register_chrome_launcher.bat   # Регистрация протокола manga-translator:// в реестре Windows (ASCII + CRLF)
├── translate_folder.bat           # Пакетный перевод папки с продолжением с места остановки (ASCII + CRLF)
├── test_page.bat                  # Быстрый тест перевода одной страницы (ASCII + CRLF)
└── extension\                     # Папка расширения для Chrome (Manifest V3 v0.9.9)
    ├── manifest.json
    ├── background.js
    └── content.js
```

## 3. Изменения в версии v0.9.9
1. **Локальный графический интерфейс (`gui_app.py` + `start_gui.bat` + `web_studio.html`):**
   * Полноценное десктопное приложение на `Tkinter` + `Pillow` (не требует браузера Chrome и не требует установки новых библиотек через `pip`).
   * Автоматически проверяет и при необходимости запускает локальный сервер `server.py` в фоне.
   * Отображает список всех страниц выбранной папки со статусами (`✅ Переведена` / `⏳ Ожидает`), визуальное сравнение «До и После» (Оригинал слева, Перевод справа) и таблицу всех распознанных реплик на странице.
2. **Умное продолжение перевода папки (`skip_existing=True`) и остановка (`POST /folder_stop`):**
   * При выборе папки и запуске перевода проверяется целевая папка `<Папка>_<ЯЗЫК>` и файл `.translation_state.json`.
   * Все уже переведенные страницы автоматически пропускаются, а перевод продолжается строго с первой непереведенной страницы с сохранением контекста диалога (`rolling_context`).
   * Кнопка «⏹ Остановить перевод» корректно останавливает пакетный процесс после текущей страницы.
3. **Выборочный и повторный перевод отдельных страниц (`POST /translate_page_file`):**
   * Кнопка «🎯 Перевести выбранную страницу» позволяет перевести только одну (или несколько выделенных) страниц из папки, не запуская перевод всей папки.
   * Кнопка «🔁 Перевести заново (исправить)» принудительно берет чистый исходник выбранной страницы и заново выполняет перевод с текущими настройками, перезаписывая неудачный файл в выходной папке.
   * Кнопка «📄 Отдельный файл...» позволяет выбрать и перевести любую отдельную картинку на диске.
4. **Настройка минимального и максимального размера шрифта (`min_font_size` и `max_font_size`):**
   * В `renderer.py`, API сервера, десктопном GUI, веб-студии и расширении Chrome добавлены оба ползунка/поля: минимальный кегль шрифта (по умолчанию `12px`) и максимальный кегль шрифта (по умолчанию `32px`).
5. **Перевод текста вне speech bubbles (`detect_free_text=True`):**
   * В `ocr_engine.py` добавлен второй проход детекции по замаскированной от бабблов странице (CRAFT детектор из EasyOCR + морфологический детектор контрастных штрихов OpenCV) с группировкой вертикальных и горизонтальных колонок и защитой от галлюцинаций `MangaOCR`.
   * В `cleaner.py` и `renderer.py` для свободных надписей (`is_free_text=True`) применяется расширенная маска очистки обводки и прямоугольная верстка с автоматическим расширением узких вертикальных колонок.
6. **Перевод с японского на Ромадзи (`target_lang="romaji"`):**
   * В `translator.py` добавлен режим транслитерации японского текста в Хэпбёрн-ромадзи (`_ROMAJI`) через LLM (для точного контекстного чтения кандзи с разбивкой на слова) + встроенный детерминированный конвертер хираганы/катаканы `kana_to_romaji`.

## 4. Изменения в версии v0.9.9 (Ручное редактирование перевода + Кнопка Ромадзи)
1. **Ручное редактирование перевода любой страницы (`POST /save_edited_page` и `POST /page_blocks`):**
   * При переводе папки или отдельных страниц все распознанные текстовые блоки (`id`, `bbox`, `original_text`, `romaji_text`, `translated_text`, `is_free_text`, `font_size`) сохраняются в `.translation_state.json`.
   * В Веб-Студии (`web_studio.html`) и десктопном GUI (`gui_app.py`) можно выбрать любую переведенную страницу, нажать **«✏️ Редактировать перевод и Ромадзи»** (или **«✏️ Редактор»**), изменить текст в любом баббле или надписи (а также при желании выбрать индивидуальный размер шрифта для конкретного баббла) и нажать **«💾 Сохранить результат»** (`Ctrl+S`).
   * Страница мгновенно перерисовывается с чистых исходников (без повторного вызова OCR и без траты токенов ИИ) и сохраняется в выходную папку `<Папка>_<ЯЗЫК>`, а исправленные фразы запоминаются в кэше перевода главы.
   * В Веб-Студии при открытии редактора на самой странице манги отображаются интерактивные номерные метки `#1, #2, ...` по координатам бабблов (клик по бабблу на странице сразу фокусирует нужное текстовое поле).
2. **Кнопка показа и генерации Ромадзи (`🔤 Ромадзи` / `POST /page_romaji`):**
   * В верхней панели просмотра и внутри редактора добавлена кнопка **«🔤 Ромадзи»**, которая показывает под каждой японской фразой её чтение латиницей (Хэпбёрн-ромадзи).
   * В `translator.py` добавлен быстрый встроенный конвертер `japanese_to_romaji_local` (словарь частых слов и кандзи манги + разбор грамматических частиц + `kana_to_romaji`), работающий мгновенно и без интернета/ИИ, а также кнопка **«✨ Уточнить Ромадзи (ИИ)»** (`POST /page_romaji`) для контекстного чтения редких кандзи через активную модель Ollama / Cloud API.

## 7. Обновление интерфейса и редактора (Адаптивный UI, 5 режимов редактора и Новые Настройки с вкладками)
1. **Переключаемое расположение панели редактора (`editor_dock_mode`: `right` / `bottom` / `floating`):**
   * **➡ Сбоку (Справа)** — боковая колонка справа от страницы манги с перетаскиваемой границей ширины (`.panel-splitter`). Страница манги всегда видна во всю высоту от верха до самого низа без перекрытий.
   * **⬇ Снизу (Сплиттер)** — панель под страницей манги в честном flex-контейнере с перетаскиваемой границей высоты и гарантированной прокруткой страницы манги до самого нижнего края.
   * **🪟 Плавающее окно** — перетаскиваемое мышкой мини-окно поверх рабочей области с кнопкой **«— Свернуть»** (сворачивается в узкую полоску-заголовок) и режимом **«👻 Авто-прозрачность»** (`floating_auto_fade`), при котором окно становится полупрозрачным, когда курсор мыши находится на странице манги.
2. **Компактный всплывающий попап прямо у кружка `#N` (`inline_bubble_popup=True`):**
   * Клик по любой интерактивной рамке `#N` на странице манги мгновенно открывает рядом с бабблом компактное всплывающее окно (`#inline-bubble-popup`) с оригиналом, Ромадзи, полем перевода, выбором размера шрифта, переключением `◀ / ▶` между кружками и кнопками `💾 Применить (Ctrl+S)`, `🔄 ИИ`, `🗑 Удалить`.
   * Переключатель **«📌 Метки #N»** (`always_show_pins=True`) позволяет видеть рамки всех распознанных блоков на переведенной странице и редактировать их по клику даже без открытия большой панели редактора.
3. **Честная прокрутка до самого низа, сплиттеры панелей и авто-центровка (`auto_scroll_to_bubble=True`):**
   * При выборе или фокусе карточки блока `#N` в списке редактора страница манги плавно прокручивается и центрируется точно на выбранном кружке `#N` с пульсирующей подсветкой рамки.
   * Добавлены перетаскиваемые разделители (сплиттеры) как для левой панели списка страниц, так и для панели редактора (сбоку и снизу).
4. **Режим широкого экрана (`auto_collapse_sidebar`), быстрая навигация и Полный экран (`F11`):**
   * Кнопка **«◀ Панель»** (или клавиша `[`) и кнопка **«↔ Широкий экран»** в 1 клик скрывают/показывают левую колонку (маскота и список страниц), а опция авто-сворачивания в настройках делает это автоматически при открытии редактора.
   * В верхней панели просмотра добавлены кнопки быстрого переключения страниц **«◀ Пред.» / «След. ▶»** (горячие клавиши `←` / `→`), управление масштабом (`↔ Шир.`, `↕ Выс.`, `➖ / ➕`, `Ctrl + Колесико`) и кнопка **«⛶ Полный экран (F11)»**.
5. **Переработанное окно Настроек с удобными вкладками:**
   * Настройки разделены на 4 наглядные вкладки: **«🤖 ИИ и Модели»**, **«🎨 Интерфейс и Редактор»**, **«📊 Фильтр текста и SFX»**, **«🔤 Шрифт и Сохранение»** с визуальными карточками выбора, подробными пояснениями и кнопкой **«↺ Сбросить по умолчанию»**.

   * Во время перетаскивания, ресайза или прокрутки колесика внутри рамки отображается живой предпросмотр переведенного текста в реальном масштабе.
   * Обычный клик без перетаскивания по-прежнему открывает компактный попап редактирования рядом с бабблом.
   * Кнопка **«↺»** (на самой рамке, в попапе и в карточке блока) в 1 клик возвращает сдвинутую/растянутую рамку и размер шрифта к исходным координатам распознанного баббла.
2. **Автоподбор кегля от площади рамки и регулировка колесиком мыши (`renderer.py`):**
   * При изменении размера рамки за уголки/стороны (`bbox_modified=True`, `font_size=None`) `renderer.py` автоматически подбирает оптимальный размер шрифта под новую площадь квадрата в широком диапазоне `6–140px`, игнорируя глобальные лимиты `min_font_size` / `max_font_size` из настроек, и верстает текст по всей прямоугольной области.
   * Прокрутка колесика мыши прямо над рамкой `#N` (без зажатого `Ctrl`) мгновенно увеличивает или уменьшает размер шрифта (`font_size`) этого блока с шагом `±2px`.
3. **Фиксация области замазки оригинала на старом месте (`cleaner.py`, `server.py`):**
   * В модель `TextBlock` и файл `.translation_state.json` добавлены поля `clean_bbox` (исходные координаты распознанного текста), `bbox_modified` и `rendered_font_size`.
   * При сдвиге или уменьшении рамки перевода `cleaner.py` всегда затирает оригинальный японский/корейский/китайский текст строго по `clean_bbox` (в редакторе исходное место замазки показывается аккуратным пунктиром `Замазка #N`), а новый текст рисуется в `bbox`.
4. **Автоматическая перерисовка через 2,5 секунды бездействия:**
   * После любого изменения рамки мышкой, прокрутки колесика или ввода текста запускается debounce-таймер на **2,5 секунды** (`⏳ Авто-применение через 2.5с...`). Когда пользователь прекращает двигать рамки, страница автоматически перерисовывается с чистого исходника (`POST /save_edited_page`, 0 токенов ИИ) и сохраняется в выходную папку. Опцию можно включать/выключать во вкладке настроек **«🎨 Интерфейс и Редактор»**.
