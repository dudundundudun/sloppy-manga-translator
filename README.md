## 🚀 КАК ЗАПУСТИТЬ ОБЫЧНОМУ ПОЛЬЗОВАТЕЛЮ (ПРОЩЕ НЕ БЫВАЕТ — В 3 ШАГА!)

Вам **НЕ НУЖНО** быть программистом! Не нужно устанавливать Python, Rust, Git или CUDA Toolkit — программа сделает всю сложную работу **САМА**!

### Шаг 1. Скачайте и распакуйте программу
1. Перейдите в раздел **[📦 Releases (Скачать программу)](https://github.com/dudundundudun/sloppy-manga-translator/releases)** справа на странице GitHub.
2. Скачайте маленький архив **`MikoStudio-Portable-Lite-win64.zip`** (всего **~5.5 МБ** — скачивается за одну секунду!).
3. Распакуйте папку из архива в любое удобное место на диске (например, `D:\MikoStudio`).
   *(Важно: именно распакуйте архив в папку, а не запускайте прямо изнутри открытого архиваторa!)*

### Шаг 2. Запустите `MikoStudio.exe` и нажмите ОДНУ кнопку
1. Откройте распакованную папку и дважды кликните по **`MikoStudio.exe`**.
   *(Откроется небольшое чёрное окошко сервера — не закрывайте его, пока пользуетесь программой — и автоматически откроется красивая студия в вашем браузере!)*
2. При первом запуске прямо на экране появится **🦊 Мастер быстрой настройки**:
   * Программа **сама определит вашу видеокарту**: если у вас **NVIDIA (GTX / RTX)** — предложит турбо-режим **CUDA**, если **AMD / Intel / обычный ноутбук** — лёгкий **CPU-режим**.
   * Просто нажмите большую кнопку **«🚀 Скачать и настроить всё автоматически (в 1 клик)»**!
   * Подождите пару минут, пока заполнится полоска загрузки: программа сама скачает шрифты, официальные ускорители Microsoft / NVIDIA и 6 нейросетей. *(Если интернет случайно мигнёт — ничего страшного, докачка продолжится ровно с того же места!)*

### Шаг 3. Выберите, чем переводить текст (Облако или Бесплатно на своём ПК)
Прямо в том же окне (или по кнопке **⚙️ Настройки** в правом верхнем углу) выберите один из двух вариантов:

* **Вариант А — ☁️ Облачный ИИ (максимально быстро, не нагружает компьютер):**
  Вставьте ваш API-ключ (например, от DeepSeek / ModuleAPI / OpenRouter) и нажмите **«💾 Сохранить ключ»**. Готово!
* **Вариант Б — 🏠 Полностью бесплатно и без цензуры на своём ПК (через Ollama):**
  1. Нажмите кнопку **«🦙 Установить / запустить Ollama»** прямо в мастере настройки (или скачайте с [ollama.com](https://ollama.com)).
  2. Откройте **⚙️ Настройки** в студии и скачайте рекомендуемую локальную модель в 1 клик (отлично подходит для 18+ манги без отказов!).

## 📖 КАК ПЕРЕВЕСТИ ГЛАВУ ИЛИ СТРАНИЦУ МАНГИ

Когда настройка завершена, пользоваться студией — одно удовольствие:

1. **Перевести целую главу (папку с картинками):**
   * В левой панели нажмите выбор папки и укажите папку со сканами главы (`.jpg`, `.png`, `.webp`).
   * Вверху выберите язык перевода (**🇷🇺 Русский** или **🇬🇧 English**).
   * Нажмите **«Перевести папку»** — страницы начнут переводиться одна за другой прямо на ваших глазах! Готовые переведённые страницы аккуратно сохранятся рядом в отдельную папку (`_RU` или `_EN`), оригиналы никто не испортит!
2. **Подправить любую фразу вручную (если захочется идеала):**
   * Кликните мышкой по любому облачку `#1`, `#2` прямо на картинке — меняйте текст, двигайте рамку, крутите **колёсико мыши** для изменения размера шрифта или нажмите клавишу **`B`**, чтобы подкрасить фон кисточкой!
   * Зажмите **`Пробел`** (или `V`), чтобы мгновенно сравнить перевод с оригиналом.
   * **`Ctrl + Z`** отменяет любое действие!
3. **Погладьте лисичку Сэнко-Мико 🦊:**
   * В шапке есть кнопка **«🦊 Лисичка»** — маленькая пиксельная помощница гуляет прямо по студии (только осторожнее с её пушистым хвостиком!).

## ❓ ЧАСТЫЕ ВОПРОСЫ ПРОСТЫМ ЯЗЫКОМ (FAQ)

* **Нужна ли мощная видеокарта NVIDIA?**
  С видеокартой NVIDIA (RTX / GTX) программа работает с **КОСМИЧЕСКОЙ** скоростью (~0.15 секунды на чистку и распознавание страницы!). Но если у вас AMD, Intel или офисный ноутбук — просто выберите **«💻 Лёгкий CPU режим»**, всё тоже отлично работает!
* **Почему Windows SmartScreen при первом запуске может показать синее окошко «Система Windows защитила ваш компьютер»?**
  Потому что мы независимые разработчики и не платим Microsoft сотни долларов в год за коммерческий сертификат подписи. Нажмите **«Подробнее» ➔ «Выполнить в любом случае»**. Весь исходный код программы на 100% открыт прямо здесь на GitHub!
* **Как обновить программу в будущем, надо ли заново качать гигабайт моделей?**
  **НЕТ!** Все скачанные нейросети лежат у вас в папке `models/`. Чтобы обновить программу, достаточно заменить один маленький файл `MikoStudio.exe` — все ваши модели, шрифты, глоссарий и настройки останутся на месте!

## 🏆 ПОЧЕМУ ЭТОТ ДВИЖОК — ПРОСТО ФАНТАСТИКА (ДЛЯ ЦЕНИТЕЛЕЙ ТЕХНОЛОГИЙ)

* **Нативное ядро на Rust (`crates/`):** старт сервера за **10 миллисекунд**, один компактный бинарник со встроенной базой `SQLite WAL`, нулевой расход лишней памяти и никаких тормозов Python GIL!
* **Каскад из 6 ONNX-нейросетей на CUDA 13 + cuDNN 9:**
  * Детекция и точные контуры бабблов: `RT-DETR-v2` + `YOLOv8m` + полигональная сегментация `YOLO26s-seg`.
  * Мгновенное распознавание японского текста: `manga-ocr-nar-small`.
  * Нейросетевая маска букв `comic_text_segmenter` + кастомный **Anime-LaMa (Real-DFT)** инпейнтинг скринтонов и градиентов — **НИКАКИХ уродливых белых прямоугольников и грязного серого мыла на лицах персонажей!**
* **Умная комиксная вёрстка (`miko-renderer`):** ромбовидная укладка текста строго по внутренней форме облачка, автоматическая белая обводка на тёмном фоне и скринтонах, никаких кривых разрывов слов посреди строки!
* **Две редакции в одном репозитории:**
  * **Rust Portable / Turbo Studio** — основной сверхбыстрый движок (`MikoStudio.exe` / `start_rust_studio.bat`).
  * **Классическая Python-студия v6.1.0 + расширение для браузера Chrome (`extension/`)** — также полностью сохранена в репозитории (`start_gui.bat`) с поддержкой корейского/китайского `HayaiOCR` и `VLM-OCR`.

## 🛠 ДЛЯ РАЗРАБОТЧИКОВ (СБОРКА ИЗ ИСХОДНИКОВ)

Если вы клонировали репозиторий через `git clone` и хотите собрать портативные архивы самостоятельно:

* Запустите **`start_rust_studio.bat`** — соберёт и откроет Rust-студию в режиме разработки.
* Запустите **`build_portable_release.bat`** — автоматически скомпилирует и упакует в папку `dist/` сразу два готовых архива:
  1. `MikoStudio-Portable-Lite-win64.zip` (~5.5 МБ — умная версия с автодокачкой при первом старте);
  2. `MikoStudio-Portable-Full-CUDA-win64.zip` (~1.2 ГБ — полная офлайн-версия «всё включено» для переноса на флешке без интернета).
* Для запуска классической Python-версии установите зависимости `pip install -r requirements.txt` и запустите **`start_gui.bat`**.
