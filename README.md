# 🌸 Miko-chan Manga Studio (v1.0.0)

Локальная студия автоматического перевода и тайпсеттинга манги (🇯🇵 JA), манхвы (🇰🇷 KO) и маньхуа (🇨🇳 ZH) на русский и английский языки (а также транслитерации в Хэпбёрн-Ромадзи `🔤 Romaji`) с интерактивным веб-редактором, нейросетевой очисткой бабблов (SimpleLama / OpenCV) и расширением для браузера Chrome.

## ✨ Основные возможности v1.0.0

* **Интерактивная Веб-Студия (`web_studio.html`)**:
  * **3 режима расположения редактора**: боковая колонка справа (`➡ Сбоку` — без перекрытия страницы), нижняя панель с перетаскиваемым сплиттером (`⬇ Снизу`) и перетаскиваемое плавающее мини-окно (`🪟 Окно`) с авто-прозрачностью и сворачиванием в полоску.
  * **Компактный попап у кружка `#N` по клику**: клик по любой рамке `#N` прямо на странице манги открывает мини-редактор рядом с облачком (`💾 Применить`, `🔄 ИИ`, `🗑 Удалить перевод`, индивидуальный размер шрифта).
  * **Ручное обведение текста (`➕ Обвести`)**: выделение любого пропущенного кружка или текста рамкой мыши для принудительного OCR и перевода.
  * **Точечное удаление перевода (`🗑 Удалить`)**: мгновенное восстановление оригинального рисунка и текста на любом блоке без замазки.
  * **Режим широкого экрана и Полный экран (`F11`)**: сворачивание левой панели в 1 клик, быстрые кнопки `◀ Пред. / След. ▶` и плавный зум (`Ctrl + Колесико`).
* **Умная фильтрация вздохов и спецэффектов (`dialogue_only`)**:
  * Защита рисунка от лишней замазки: автоматический пропуск коротких вздохов («а», «о», «ах», «ох», «мм») и звуковых спецэффектов (SFX), с сохранением коротких важных реплик внутри бабблов (`マジ`, `ダメ`, `ウソ`, `バカ`, `イヤ`).
* **Гибкая работа с ИИ (Облако + Локальные модели)**:
  * Пресеты в 1 клик для **DeepSeek Flash (`deepseek-v4-flash`)** и **DeepSeek Pro (`deepseek-v4-pro`)** через шлюз ModuleAPI.
  * Автоматическое скачивание лучших локальных моделей для манги (**Shisa V2.1 14B / 8B**, **Shisa V2 12B Uncensored**, **Gemma 3 12B**, **Qwen 2.5 14B**) через Ollama с обходом блокировок VPN Fake-IP.
  * Пакетный перевод глав (по 12 страниц за 1 запрос к ИИ) с сохранением контекста диалога и продолжением с места остановки.

## 🚀 Быстрый запуск

1. Запустите **`start_gui.bat`** — скрипт автоматически запустит локальный FastAPI-сервер на `http://127.0.0.1:5000/` и откроет окно **Miko-chan Manga Studio**.
2. Для запуска запасного десктопного интерфейса на Tkinter используйте **`start_tk_gui.bat`**.
3. Для установки расширения Chrome откройте `chrome://extensions/`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку **`extension/`**.

## 📁 Структура проекта

* `web_studio.html` — основной интерфейс Веб-Студии
* `server.py` — локальный FastAPI-сервер (`127.0.0.1:5000`)
* `ocr_engine.py` — детекция бабблов (YOLOv8 + контурный детектор OpenCV) и распознавание текста (MangaOCR / EasyOCR)
* `translator.py` — переводчик и конвертер Ромадзи (DeepSeek API / Ollama)
* `cleaner.py` — очистка текста (SimpleLama GPU / OpenCV TELEA)
* `renderer.py` — овальная и прямоугольная верстка перевода в бабблы
* `gui_app.py` — автономный десктопный интерфейс на Tkinter
* `extension/` — расширение для перевода манги прямо в браузере Chrome
* `config.example.json` — шаблон конфигурационного файла (рабочий `config.json` с ключами API добавлен в `.gitignore`)
