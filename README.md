# 🌸 Miko-chan Manga Studio (v1.0.8 · Pro Scanlation Typesetting Edition v3.5)

Локальная десктопная и веб-студия автоматического перевода и профессионального тайпсеттинга манги (🇯🇵 JA), манхвы (🇰🇷 KO) и маньхуа (🇨🇳 ZH) на русский (`ru`), английский (`en`) и транслитерации в Хэпбёрн-Ромадзи (`🔤 Romaji`) с интерактивным редактором, двухконтурной нейросетевой детекцией, очисткой бабблов (SimpleLama GPU / OpenCV) и расширением для браузера Chrome (Manifest V3).

## ✨ Основные возможности v1.0.8

* **Продвинутый мультиязычный OCR и детекция (Шаги 1–4)**:
  * **Двухконтурная детекция (`RT-DETR-v2` + `YOLOv8m` + OpenCV)**: раздельные контуры `bbox` (область верстки), `clean_bbox` (область замазки) и `text_bbox` (плотный внутренний контур чернил букв для защиты рисунка).
  * **Гибридный японский OCR 2026**: скоростной `muscgab/manga-ocr-nar-small` (~35 мс на страницу) в каскаде с `MangaOCR FP16` для длинных монологов.
  * **Мультиязычный OCR для корейской манхвы (`ko`) и китайской маньхуа (`zh`)**: нативная PyTorch-модель `JustANormalTinkerer/hayai-ocr-v2.5-nova` (`SigLIP2 NaFlex`) + умная построчная сегментация вебтунов (`_split_horizontal_lines_for_ocr`) + поддержка `RapidOCR` / `EasyOCR`.
  * **Снайперский `👁 VLM-OCR`**: чтение сложных рукописных спецэффектов (SFX), изогнутых логотипов и цветных обложек при выделении `➕ Обвести` или по кнопке `👁 VLM-OCR` через локальные Vision-модели Ollama (`GLM-OCR 0.9B`, `Qwen 2.5 VL 7B`) или облачный Vision API.
* **Профессиональный тайпсеттинг (`v3.5 Pro Scanlation Edition`)**:
  * **Геометрический анализ бабблов (`Distance Transform` / `Pole of Inaccessibility`)**: сегментация внутренней полости облачка с защитой от протечек (`Leakage Guard`), отсечением хвостика речи и поиском оптического центра.
  * **2D-DP «алмазная» верстка (`💎 Алмаз`) и сокращение фраз (`✂️ Сократить`)**: укладка строк по профилю суперэллипса Ламе, слоговой перенос для русского языка без висячих предлогов, правило `Crossbar-I` и гармонизация кегля на уровне всей страницы.
  * **Локальная ретушь маски (`B`)**: мгновенная (< 2 мс) кисть и ластик замазки поверх двухуровневого кэша `SimpleLama`.
* **Интерактивная Веб-Студия (`web_studio.html`) и воркфлоу сканлейтера**:
  * **3 режима стыковки редактора**: боковая панель справа (`➡ Сбоку`), нижняя панель (`⬇ Снизу`) и плавающее окно (`🪟 Окно`), плюс компактный попап прямо у кружка `#N`.
  * **Стек `Undo / Redo` (`Ctrl+Z` / `Ctrl+Y`)**, объединение (`Merge`, `M`) и разделение (`Split`) рамок, быстрые клавиши сверки с оригиналом (`Space` / `V`).
  * **Глоссарий (`Sakura` / `.json` / `.tsv`), Глобальный поиск и замена (`Ctrl+F` / `Ctrl+H`) и Книжный режим главы (`📖 Книга главы`)** с литературной ИИ-вычиткой.
* **Гибкая работа с ИИ (Облако + 10 локальных моделей в 1 клик)**:
  * Пресеты в 1 клик для **DeepSeek Flash (`deepseek-v4-flash`)** и **DeepSeek Pro (`deepseek-v4-pro`)** через шлюз ModuleAPI с автоматическим локальным обходом облачной цензуры через Ollama.
  * Скачивание 10 лучших локальных моделей (**Shisa V2.1 14B / 8B**, **Shisa V2 12B Uncensored**, **Sugoi 14B Ultra**, **TranslateGemma 12B**, **Aya Expanse 8B**, **Gemma 3 12B**, **Qwen 2.5 14B**, **GLM-OCR 0.9B**, **Qwen 2.5 VL 7B**) с авто-обходом блокировок VPN Fake-IP (`198.18.x.x`).

## 🚀 Быстрый запуск

1. Запустите **`start_gui.bat`** — скрипт запустит локальный FastAPI-сервер на `http://127.0.0.1:5000/` и автоматически откроет окно **Miko-chan Manga Studio v1.0.8**.
2. Для запуска автономного десктопного интерфейса на Tkinter используйте **`start_tk_gui.bat`**.
3. Для установки расширения Chrome (`v1.0.8`) откройте `chrome://extensions/`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку **`extension/`**.

## 📁 Структура проекта

* `web_studio.html` — основной интерфейс Веб-Студии (`v1.0.8`)
* `server.py` — локальный FastAPI-сервер (`127.0.0.1:5000`, `v1.0.8`)
* `ocr_engine.py` — двухконтурная детекция (`RT-DETR-v2` + `YOLOv8m`) и гибридный OCR (`manga-ocr-nar-small`, `MangaOCR`, `HayaiOCR v2.5 Nova`, `VLM-OCR`)
* `translator.py` — переводчик, менеджер глоссария и конвертер Ромадзи (`DeepSeek API` / `Ollama` / `GGUF`)
* `cleaner.py` — инпейнтинг текста и сегментация геометрии бабблов (`SimpleLama GPU` / `OpenCV TELEA`, `v3.5`)
* `renderer.py` — 2D-DP «алмазная» верстка и типографика (`v3.5 Pro Scanlation Edition`)
* `gui_app.py` — автономный десктопный интерфейс на Tkinter (`v1.0.8`)
* `cli_client.py` — консольный клиент пакетного перевода и выбора моделей (`v1.0.8`)
* `extension/` — расширение для перевода манги прямо в браузере Chrome (`Manifest V3`, `v1.0.8`)
* `config.example.json` — шаблон конфигурационного файла (рабочий `config.json` с ключами API добавлен в `.gitignore`)
